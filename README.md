# Student Grade Calculator

## Description

Student Grade Calculator is a web application that allows users to calculate students' academic performance based on assessment scores.

The application calculates:

- Total Score
- Average Score
- Grade (A–F)
- Pass/Fail Status

It also stores student records using the browser's Local Storage.

---

## Features

- Add student records
- Calculate total score
- Calculate average score
- Assign grades automatically
- Display pass/fail status
- View all student records
- Delete student records
- Store records using Local Storage

---

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage

---

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.

No installation is required.
